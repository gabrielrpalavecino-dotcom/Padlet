# 🌸 Avril Padlet — Archivo Creativo Anime

Repositorio oficial donde se organiza todo el contenido creativo de **Avril**, artista de estilo **anime japonés moderno**, con enfoque narrativo y visual.  
Aquí se guardan automáticamente ilustraciones, textos, ideas, historias y comentarios, siguiendo una estética **sakura**, suave pero madura.

---

## ✦ Estructura del repositorio
- Galería Anime  
- Contenido IG  
- Textos / Historias  
- Comentarios / Notas
